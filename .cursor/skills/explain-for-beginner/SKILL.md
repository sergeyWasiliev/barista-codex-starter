# Explain for beginner

## Когда включать

Пользователь учит код этого репозитория, а не просит сразу патч.

## Как объяснять

1. Одно предложение: роль фрагмента в системе.
2. Таблица или список «строка → смысл».
3. Связь со следующим слоем (кнопка → `api.js` → route → controller → service → repo).
4. Мини-словарь: `async/await`, `fetch`, `req.params`, `204`, `fs.unlink`.
5. Пример с конкретным `id`, если есть HTTP.

## Не делать

- Не переписывать код «чище», пока не попросили.
- Не лить весь файл — цитата 5–20 строк.
- Не говорить «это стандартный Express» без расшифровки.
