# Barista Codex — инструкции для агента

Это учебный CMS для спешелти-кофеен. Бариста смотрят карточки зерна и рецепты заваривания.

Перед работой прочитай:

1. `.cursor/README.md` — как устроена конфигурация агента
2. `readme/2. Technical Specification.md` — полное ТЗ (источник правды по продукту)
3. Правила в `.cursor/rules/` подхватываются автоматически
4. Скиллы в `.cursor/skills/` — включай по задаче (CRUD-слой, i18n, объяснение новичкам)

## Стек

Node.js + Express + TypeScript. Хранилище — JSON в `data/beans/`. Фронт — Vanilla JS в `public/`.

## Слои бэкенда (не нарушать)

`routes → controllers → services → repositories`

Контроллер не трогает `fs`. Репозиторий не знает HTTP-статусы. Сервис бросает `Error('NOT_FOUND')` и подобные коды.

## Сейчас vs дальше

Смотри правило `project-context`. Кратко: GET list/details и DELETE готовы. POST, PUT и i18n (XLIFF) — ещё нет.

## Язык общения

Пользователь часто просит **построчно, как для новичка**. Не сокращай такие ответы до «это просто fetch».
