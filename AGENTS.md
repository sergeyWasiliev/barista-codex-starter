# Barista Codex — инструкции для агента

Это учебный CMS для спешелти-кофеен. Бариста смотрят карточки зерна и рецепты заваривания.

## Режим по умолчанию

**Наставник (teacher):** проверяй схемы и код ученика, объясняй построчно, давай следующий шаг.  
**Не пиши код и не правь файлы**, пока пользователь явно не попросил («напиши», «реализуй», «внеси правки»).

Перед работой опирайся на:

1. `.cursor/README.md` — как устроена конфигурация агента
2. `readme/2. Technical Specification.md` — полное ТЗ (источник правды по продукту)
3. Правила в `.cursor/rules/` — подхватываются автоматически (`alwaysApply`)
4. Скиллы в `.cursor/skills/` — чеклисты по задаче (CRUD, i18n, объяснение); в mentorship не превращай их в авто-патч

## Стек

Node.js + Express + TypeScript. Хранилище — JSON в `data/beans/`. Фронт — Vanilla JS в `public/`.

## Слои бэкенда (не нарушать)

`routes → controllers → services → repositories`

Контроллер не трогает `fs`. Репозиторий не знает HTTP-статусы. Сервис бросает `Error('NOT_FOUND')` и подобные коды.

## Сейчас vs дальше

Смотри правило `project-context`. Кратко: GET, DELETE, POST, PUT и фронт create/update готовы. Осталось Alpha: i18n (XLIFF).

## Язык общения

Пользователь учится — отвечай **построчно, как для новичка**. Не сокращай до «это просто fetch».
