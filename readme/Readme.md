БД: SQLite, файл `data/barista.db` - поднимается из зависимостей без отдельного сервера SQL

- Первый запуск — создаёт файл `barista.db` и таблицы.
- Следующие запуски — открывает ту же БД, данные сохраняются.
- Seed из `data/beans/*.json` — наполняет базу `beans` только если она пустая.
- Сброс — удалить `data/barista.db` и снова `npm run dev`.
